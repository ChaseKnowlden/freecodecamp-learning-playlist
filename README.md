# FreeCodeCamp Learning Workspace

This repository is organized as a study and project workspace for the two FreeCodeCamp-inspired learning playlists below:

- Front End Developer Roadmap: https://www.youtube.com/playlist?list=PLWKjhJtqVAbmMuZ3saqRIBimAKIMYkt0E
- Back End Developer Roadmap: https://www.youtube.com/playlist?list=PLWKjhJtqVAbn21gs5UnLhCQ82f923WCgM

The goal is to use this space to track progress, build front-end and back-end exercises, and keep notes, code, and projects in one place.

## Repository structure

- `backend/` — server-side projects, APIs, databases, and back-end learning work
- `frontend/` — client-side app code, UI work, and front-end practice
- `html/` — HTML-focused demos, exercises, and landing pages
- `shared/` — reusable assets, utility code, or shared resources across the project

## Playlist 1: Front End Developer Roadmap

This track focuses on the fundamentals of modern front-end development and web design.

### Included topics

- Front-end developer roadmap and learning path
- HTML crash course for beginners
- CSS fundamentals and layout techniques
- Visual Studio Code setup and workflow
- JavaScript programming foundations
- Building a strong base for web development projects

### Suggested progression

1. Start with the roadmap video to understand the full front-end path.
2. Complete the HTML and CSS lessons before moving into JavaScript.
3. Use the VS Code crash course to improve productivity and workflow.
4. Practice by creating small front-end projects in `frontend/` and `html/`.

### Key learning outcomes

- Understand how a web page is structured
- Build responsive and styled interfaces
- Write client-side logic in JavaScript
- Use modern dev tooling and editor workflows

## Playlist 2: Back End Developer Roadmap

This track introduces the server-side side of web development, including full-stack concepts and common backend tools.

### Included topics

- Back-end developer roadmap
- Full stack web development for beginners
- Node.js and JavaScript server-side concepts
- Python fundamentals and mini-projects
- Django development for building applications
- Git and GitHub basics for version control

### Suggested progression

1. Begin with the back-end roadmap to understand the architecture and tools.
2. Move through the full-stack intro to see how front-end and back-end connect.
3. Practice Python and Django fundamentals in `backend/`.
4. Use Git and GitHub consistently to manage code versions and collaboration.

### Key learning outcomes

- Understand how web apps communicate between client and server
- Create backend logic and APIs
- Learn Python and Django-based application development
- Use Git and GitHub for source control and project management

## Recommended learning plan

A practical order for this workspace could be:

1. Complete the front-end course sequence in the first playlist.
2. Build simple HTML/CSS/JavaScript exercises in `html/` and `frontend/`.
3. Move into the backend roadmap and full-stack topics.
4. Add backend projects, API work, and database-related learning in `backend/`.
5. Keep shared code, notes, and reusable assets in `shared/`.

## Notes

This repo is intentionally lightweight and can be extended as projects grow. Each directory can be used to organize notes, mini apps, exercises, and milestones as progress moves through the guided playlists.
