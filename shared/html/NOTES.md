# HTML
HTML stands for HyperText Markup Language, it is used to create webpages.

## Usage
Every website on the internet uses HTML and CSS, most also use JavaScript.  HTML is the Structure, CSS is the Style, and JavaScript is the Functionality.

### How to see the HTML
Right click on an element, and select Inspect.

## HTML Elements
HTML is made up of elements.  An element is an individual component of HTML.  An element will often have an opening and closing tag, and content inside the opening and closing tag, a closing tag will also often have a slash inside the angled brackets right before the name of the tag.  Most HTML elements are containered elements that hold content between the opening and closing tags.

### DOCTYPE html
[DOCTYPE html](https://developer.mozilla.org/en-US/docs/Glossary/Doctype) is what all HTML files are going to start with.  This is also the first element on every HTML webpage.  It tells the browser to expect HTML and what version to use, and DOCTYPE html just means to use the latest version of HTML.
